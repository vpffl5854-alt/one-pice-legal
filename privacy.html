1. 수집하는 정보

one-pice는 Google 계정 인증 과정에서 다음 정보에 접근합니다.

  • OAuth 인증 토큰 (액세스 토큰, 리프레시 토큰)
  • 사용자가 승인한 YouTube 채널의 기본 정보 및 업로드 결과 정보
  • 도구가 업로드하는 영상 파일 및 그 메타데이터(제목, 설명, 공개 범위)

이름·주소·전화번호·결제 정보 등 그 밖의 개인정보는 수집하지 않습니다.

2. 이용 목적

수집한 정보는 사용자 본인의 YouTube 채널에 영상을 업로드하고 업로드 결과를 확인하는 목적으로만 사용됩니다.

3. 보관 및 파기

인증 토큰은 사용자의 기기(로컬 환경)에만 저장되며, 별도 서버로 전송되거나 제3자에게 제공되지 않습니다. 사용자가 저장된 토큰을 삭제하거나 Google 계정 설정에서 액세스를 철회하면 즉시 파기됩니다.

4. 제3자 제공

one-pice는 수집한 정보를 제3자에게 판매·대여·제공하지 않습니다. 정보는 사용자가 승인한 범위 내에서 Google의 YouTube API로만 전송됩니다.

5. Google API 서비스 사용자 데이터 정책

one-pice의 Google API 사용은 Google API 서비스 사용자 데이터 정책을 준수합니다. YouTube API에서 얻은 데이터는 기능 제공 목적 외로 사용하지 않으며, 광고 목적으로 사용하거나 제3자와 공유하지 않습니다.

6. 사용자의 권리

사용자는 언제든지 Google 계정 권한 페이지에서 one-pice의 액세스를 철회할 수 있습니다. 철회 시 저장된 토큰은 더 이상 사용할 수 없습니다.

Effective: 2026-11-23

1. Information we access

  • OAuth tokens (access and refresh tokens)
  • Basic information about the YouTube channel the user authorizes, and upload result data
  • Video files uploaded by the tool and their metadata (title, description, visibility)

No other personal data such as name, address, phone number, or payment information is collected.

2. Purpose

Accessed information is used only to upload videos to the user's own YouTube channel and to verify upload results.

3. Storage and deletion

OAuth tokens are stored only on the user's own device (local environment) and are never sent to a separate server or shared with third parties. Tokens are destroyed immediately when the user deletes them or revokes access in their Google Account settings.

4. Third parties

one-pice does not sell, rent, or provide accessed information to third parties. Data is transmitted only to Google's YouTube API within the scopes the user approved.

5. Google API Services User Data Policy

one-pice's use of Google APIs complies with the Google API Services User Data Policy, including the Limited Use requirements. Data obtained from the YouTube API is not used for any purpose other than providing the tool's features, is not used for advertising, and is not shared with third parties.

6. Your rights

You can revoke one-pice's access at any time at Google Account permissions. Once revoked, stored tokens can no longer be used.
